# LyophilizationCurveViewer
1. 数据导入与解析：支持 xlsx/xls/xlsm/csv，自动识别表头、时间轴与过程变量，自动去重、排序、过滤空行；CSV 具备 BOM 检测、UTF-8 校验与 GB18030 回退。 2. 变量智能识别：按关键字自动归类时间轴、温度（冷阱/板层/样品）、真空度及忽略列，支持手动调整列类型。 3. 双 Y 轴曲线可视化：温度轴 −150～100 ℃、真空度轴 0～100/1000 Pa 可切换；多变量同图叠加、勾选显隐，越限自动钳位，LTTB 降采样，十字准星读取同时刻数值。 4. 时序统计：自动计算开始/结束时间与累计运行时长。 5. PDF 报告导出：A4 横向输出含标题、图例与时间信息的曲线报告。 6. 历史记录管理：本地保存最近 20 条，支持快速重载、单条删除与清空。
