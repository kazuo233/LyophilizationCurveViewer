# LyophilizationCurveViewer｜冻干曲线查看器
冻干工艺数据解析与可视化工具，用于冻干机温度、真空度时序曲线查看分析
1. 数据导入与解析：支持 xlsx/xls/xlsm/csv，自动识别表头、时间轴、过程变量，自动去重、排序、过滤空行；CSV 自带BOM检测、UTF-8校验、GB18030编码兼容。
2. 变量智能识别：按关键字自动区分时间轴、温度（冷阱/板层/样品）、真空度、忽略列，支持手动修改列类型。
3. 双Y轴曲线可视化：温度范围 −150～100 ℃，真空度 0～100/1000 Pa 可切换；多曲线叠加、显隐控制、越限钳位、LTTB降采样、十字准星读数。
4. 时序统计：自动计算起止时间、累计运行时长。
5. PDF报告导出：A4横向导出带标题、图例、时间信息的曲线报告。
6. 历史记录管理：本地缓存最近20条记录，支持重载、单条删除、一键清空。
